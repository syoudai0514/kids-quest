# マナエボ ✨

**まなびが、進化になる。** 5歳（年長）〜小6向けの毎日学習アドベンチャー。学ぶことで「マナ」が生まれ、
相棒モンスター **ホッシュ** といっしょに国語・書字・算数・生活・理科・社会・道徳・英語を学びます。
「勉強」ではなく「あそびの延長」に感じられることを最優先に設計しています。

> Android タブレットのブラウザで動く **React + PWA（オフライン対応）**。
> アカウント登録不要・データは端末内のみに保存。
> 公開URL: https://syoudai0514.github.io/mana-evo/

---

## あそびの流れ

1. **はじめて**: 相棒ホッシュと出会い、すきな色を選んで出発（オンボーディング）
2. **ホーム＝宇宙の旅のハブ**: いまいる惑星で空の色が変わる。
   きょうのミッション5つ＝**航路マップ**をロケットが進み、次の惑星に到着すると
   物語が進んで、なかまが増える（全10惑星）
3. **タスク**: 国語・算数は5問、通常教科は4問、道徳は2問。正解のたびに褒め＋✨ほしのかけら（XP）
4. **相棒が育つ**: XPでレベルアップ＋進化。連続日数🔥ストリークも表示
5. **息抜きバトル**: 1日1回＋「ついか問題」で得たチケット分。
   勝つと「ほしのわ」でモンスターを捕まえ、**ずかん1000体**を埋めていく

## 学年レベル（年長〜小6・先取り対応）

- ホームの学年バッジから **年長→小1→…→小6** を切り替え。
  次の学年は、収録している基礎単元ごとに「4問以上・初回正解3問以上・別日2回成功」に加え、
  固定教材は異なる知識2項目（算数は同じ技能の別日確認）を満たした後、
  ほしのしれん（2日×6問、9/12以上かつ主要教科で正解）に合格すると解放
- さんすう: 九九・わり算・筆算・分数・小数・百分率・比・速さまで64種の出題タイプ
- こくご: 収録漢字・熟語の読み＋なぞり書き。学年配当の完全網羅ではなく、収録範囲の練習
- 保護者画面から先取り解放・学年変更も可能

## とっくん（失敗を宝物に変える仕組み）

- まちがえた問題は「ちからのタネ」として **とっくん画面**に集まる
- とっくんや通常ミッションで克服すると **金の演出＋ボーナス✨**で
  「まちがいが ちからに なった！」
- **「まちがいから おぼえた かず」** が大きく積み上がっていく
  ＝失敗するほど知っていることが増える、を体感できる

## 「頭が良くなる」ための仕掛け

- **アダプティブ難易度**: 2連続正解でレベルアップ（得意はどんどん先へ）。
  ミスしても責めず、ヒント→正解を光らせ**音声で解説**（苦手意識を作らない）
- **復習キュー（想起練習）**: 初回正解も含めて1→3→7→14→30日後に再確認。同じ日に連続正解しても復習段階は進めない。
  算数は単元ごとの別類題、固定知識は同じ知識IDで再確認。タスク内の誤答だけは2問後に同じ設問を出す
- **英語**: 一度に全単語を出さず、あいさつ・色・数など小さなテーマを「見本→認識→別日の想起」で進める。
  英語の習得表示は1・3・7・14日後の確認を終えてから
- **算数教具の視覚化**: かぞえる・たしざんは**5個ずつの列**（5のかたまり感覚）、
  10づくりは**10のフレーム**（2×5マス）で見せる
- **書字の3段階**: 文字ごとに **お手本アニメ→なぞり→別日後の自由書き**。
  収録文字は10〜20文字の小グループ単位で進める
- **バトルの三すくみ**: 🔥→🌿→💧→🔥（⭐は安定）。相手の属性を見て
  効くわざを推論する＝遊びながら論理を学ぶ

## 収録コンテンツ

- **よむ**: 224語＋学年別の収録漢字・熟語（小1漢字80字、小2漢字159字、小3以降も収録範囲を練習）
- **かく**: ひらがな・カタカナ・各学年の収録漢字を15文字前後のグループで練習（学年配当の完全網羅ではありません）
- **すうじ・算数**: かぞえる・筆算・九九・わり算・分数・小数・割合・比・速さなど64種
- **理科・社会**: 理科55問、社会51問。各必須単元に異なる事実問題を2問以上収録
- **英語**: 202語・50表現・アルファベット22項目。テーマ順＋別日復習
- **道徳**: 22場面。正解だけが長く見えない選択肢に調整
- **モンスター**: 1000体（独自デザイン。既存IP不使用）
- **音**: 効果音はエコー・和音つきのリッチ合成、BGMは宇宙アンビエント（すべてWeb Audio合成・ファイル不要）

## うごかし方

```bash
npm install
npm run dev        # 開発サーバ
npm run build && npm run preview   # 本番ビルド確認
```

`main` に push すると GitHub Actions が自動で GitHub Pages にデプロイします。
タブレットでは Chrome の「ホーム画面に追加」で全画面・オフラインのアプリになります。

### Lunaに任せる場合

教材追加・画像差し替え・軽い見た目調整は、リポジトリ直下の
[`AGENTS.md`](./AGENTS.md) に沿えば安全に進められます。Lunaは作業ブランチで
検証まで行い、`main` への公開は行いません。音声・書き取り・保存・PWA設定は、
安定性のためTerra/Sol向けの領域です。

## 設計（拡張しやすさ重視）

```
src/
├─ engine/
│  ├─ tts.js          日本語の音声読み上げ（指示・問題・正誤は必ず声でも）
│  ├─ sfx.js          効果音＋モンスターの鳴き声（Web Audio合成・ファイル不要）
│  ├─ storage.js      localStorage 永続化＋日付ロールオーバー
│  ├─ difficulty.js   難易度の自動調整（分野ごとの習熟度）
│  ├─ battle.js       バトルの属性相性・ダメージ計算
│  ├─ activities.js   学習分野レジストリ ← 分野を足すならここ
│  ├─ missions.js     毎日ミッションの組み立て（国語・算数重視）
│  └─ learningUnits.js 単元別の習熟・しれん解放条件
├─ data/
│  ├─ monsters.js     モンスター1000体（基本デザイン＋決定論生成）
│  ├─ planets.js      惑星10個（空の色・物語・なかま解放）← 足すだけで増える
│  └─ content/
│     ├─ reading.js   よむ: 単語・熟語＋復習対応ジェネレータ
│     ├─ numbers.js   すうじ・算数: 64種の出題タイプ（学年・レベルで解禁）
│     └─ writing.js   かく: 文字プール＋復習キュー対応
├─ components/
│  ├─ Monster.jsx         モンスターSVG（絵柄8種）
│  ├─ QuestionVisual.jsx  問題の共通描画（グリッド/10フレーム/漢字…）
│  ├─ TracingCanvas.jsx   お手本→なぞり→自由書きキャンバス
│  └─ common.jsx          星背景・紙吹雪・進捗ドット
├─ screens/
│  ├─ OnboardingScreen.jsx  はじめての おはなし
│  ├─ HomeScreen.jsx        宇宙の旅ハブ（航路マップ・相棒・Lv）
│  ├─ ActivityPlayer.jsx    出題エンジン（復習・解説・コンボ）
│  ├─ BattleScreen.jsx      息抜きバトル（三すくみ・捕獲）
│  ├─ CollectionScreen.jsx  ずかん（鳴き声つき）
│  ├─ ParentScreen.jsx      保護者ビュー
│  └─ CelebrationOverlay.jsx ごほうび演出
└─ state/
   └─ GameContext.jsx  状態の中枢（XP/ストリーク/復習キュー/セーブ移行）
```

### 拡張のしかた

- **単語/漢字/文字/惑星/モンスターを足す** → 各 data ファイルの配列に1件追加するだけ
  - よむの単語は「絵文字と言葉が1対1」「同義語なし」「絵文字重複なし」を守ること
- **新しい出題タイプ** → `numbers.js` の kinds に追加し、`QuestionVisual.jsx` に
  描画が必要なら kind を1つ足す
- **新しい分野** → `data/content/` にジェネレータを作り `engine/activities.js` に登録
- コンテンツを大きく変えたら `GameContext.jsx` の `CONTENT_VERSION` を上げる
  （進捗・ずかん・レベルは保持したまま、当日ミッションだけ作り直される）

## 著作権について

モンスター・世界観・バトルはすべて独自デザインです。
既存IP（ポケモン等）の画像・名称・データは一切使用していません。

「かく」の書き順データ（`src/data/strokeOrder.js`）は
[KanjiVG](https://kanjivg.tagaini.net)（© Ulrich Apel,
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)）の
標準書き順SVGから `scripts/build-stroke-order.mjs` で自動生成しています。
