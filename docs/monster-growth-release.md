# モンスター育成 最小縦切り リリース仕様

## 対象

- 図鑑番号51〜62（内部ID `g042`〜`g053`）を未捕獲優先でバトルに出す。
- 敵を捕獲し、最大3体のチームへ追加する。先頭ではなく `activeCompanionId` を出場個体とする。
- 学習XP、バトルXP、Lv.1〜99、進化、スター覚醒、ギガスターを同じ個体IDで保持する。
- `g052` をスター覚醒例、ボス `g053` をギガスター例とする。
- `g063`〜`g087` の画像は次回更新用として保持し、このリリースでは生成を増やさない。

## 子どもの操作経路

1. ホームの「なかま・そだてる」を押す。
2. 図鑑の仲間を押し、「このこで たたかう」または「チームに いれる」を押す。
3. バトルでは大きな技ボタンを押す。ボスの予告時だけ「まもる」または「こうたい」を選ぶ。
4. 条件を満たした個体は図鑑詳細の「しんか」「スターかくせい」「ギガスター」を押す。
5. 解放済み形態とゲージ100が揃うと、バトル中に形態ボタンが出る。

## 保存形式 v4

- 既存のlocalStorageキーとプロフィール封筒は変更しない。
- 既存の図鑑、全体XP、学年、SRS、英語、当日ミッション、武器、3戦、チケットを先に復元し、仲間項目を追加する。
- `companions` は不変の `companion:<捕獲時monsterId>` キーで保存する。進化してもキーと `sourceMonsterId` は変えず、`currentMonsterId` だけを進める。
- `party` は最大3件、`activeCompanionId` は必ずparty内へ修復する。
- 未知の旧図鑑IDは `unlockedMonsters` から削除しない。マスターに存在するIDだけ仲間化する。
- 移行は冪等で、1000体を仲間化したJSONは750KiB未満を合格条件とする。

## 報酬と不正対策

- Lv曲線は `6 × (level - 1)^2`。出場個体100%、控え70%。
- 通常学習の正解XPは回答時、タスク完了XPは完了時に付与する。
- 追加問題の正解XPは連打判定が終わるまで保留し、`suspicious` の場合は育成XPとゲージを0にする。
- 同一 `rewardKey` のタスク報酬は再付与しない。4回目以降の追加問題は逓減する。
- 勝利は出場+3/控え+1、敗北は出場+1。捕獲済みの再戦でもバトルXPは入る。

## 変更しない契約

- 基本3戦/日。
- チケット有効期限7日。
- 追加問題のチケット条件は正答率2/3以上かつ非suspicious。
- 既存の保存・学習進捗・当日ミッションを保持する。
- 画像を自動承認しない。

## 自動確認

- `node scripts/test-monster-progress.mjs`
  - v3移行、未知ID保持、冪等性、3体上限
  - 学習/控えXP、重複防止、suspicious 0報酬
  - `g042→g043` 進化、`g052` 覚醒、`g053` ギガ、ゲージ消費
  - ボス勝利、捕獲、1000体保存サイズ
- `node scripts/verify-learning-integrity.mjs`
  - 3戦、7日チケット、追加問題条件を含む既存学習契約
- `npm run build`
  - React本番ビルドとPWA service worker生成

## Claude一括レビュー観点

- v1〜v3・複数プロフィールの保存移行で既存キーを落とさないか。
- 戦闘結果が二重記録されず、交代で敵HP・ボス予告・形態使用権がリセットされないか。
- 375px/393px縦画面で図鑑詳細とバトル操作がスクロールでき、操作対象が52px以上か。
- 形態のidentityが通常個体から変わらず、ギガが3攻撃後に終了するか。
- 連打判定された追加問題から育成XP・ゲージが漏れないか。
